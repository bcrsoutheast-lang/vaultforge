FILES IN THIS BUNDLE

1. founding.html
   Replace your public founding page with this file.

2. netlify/functions/create-checkout-session.js
   Creates the Stripe subscription checkout session.

3. netlify/functions/stripe-webhook.js
   Updates member_profiles after Stripe events.

4. .env.example
   Environment variable names you need in Netlify.

WHAT THIS EXPECTS IN member_profiles

Recommended columns:
- founder_access boolean default false
- paid_member boolean default false
- stripe_customer_id text
- stripe_subscription_id text
- plan text

WHAT TO DEPLOY
- founding.html -> site root
- netlify/functions/create-checkout-session.js
- netlify/functions/stripe-webhook.js

NETLIFY ENV VARS
- STRIPE_SECRET_KEY
- STRIPE_WEBHOOK_SECRET
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY
